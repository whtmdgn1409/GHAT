# GHAT (Group Hangout & Teamplay)

다인용 화상채팅 웹 애플리케이션에 **협동형 언어 학습 게임**(단어 맞추기)을 결합한 프로젝트입니다.

## 핵심 컨셉
- 기본 화면: 다자간 화상채팅
- 게임 버튼 클릭 시: 우측 패널(div) 확장
- 확장 패널 내: 협동 단어 맞추기 게임 진행
- 학습 목적: 사용자가 잘 모르는 언어의 어휘를 맥락 기반으로 습득

## 추가 설계 범위
- **분석(Analytics)**: GA4 이벤트 설계를 통한 사용자 이용 패턴 분석
- **백엔드 API 설계**: 방/게임/단어팩/분석 이벤트 수집 엔드포인트 정의

## 설계 원칙
1. **실시간 우선**: 화상 통신/게임 동기화 모두 저지연 구조 채택
2. **모듈 분리**: Web UI, API, 실시간 이벤트, 게임 로직을 분리
3. **학습 데이터 분리**: 언어/난이도/주제별 단어팩 독립 관리
4. **AI 친화 문서화**: 상위 디렉터리별 설명 문서와 API 계약 문서 유지

## 디렉터리 빠른 보기
- `apps/`: 사용자-facing 앱(프론트/백엔드 API)
- `services/`: 실시간 통신 및 게임 엔진 백엔드 서비스
- `packages/`: 공통 라이브러리, UI 컴포넌트, 공유 타입
- `docs/`: 기획/아키텍처/개발 가이드/분석 및 API 문서
- `scripts/`: 개발/배포 자동화 스크립트
- `infra/`: 로컬/스테이징/프로덕션 인프라 정의

각 상위 디렉터리의 상세 역할은 해당 디렉터리의 `README.md`를 참고하세요.
