# apps/server

인증, 방, 게임 오케스트레이션, 분석 이벤트 수집을 담당하는 API 서버입니다.

## 주요 모듈
- `auth`: 게스트/회원 인증
- `rooms`: 방 생성/입장/퇴장
- `games`: 게임 생성/시작/추측/종료
- `word-packs`: 학습 콘텐츠 조회
- `analytics`: 이벤트 수집 및 검증

## 개발 포인트
- REST 요청 처리 후 실시간 서비스에 이벤트 발행
- Analytics 이벤트는 허용된 스키마만 통과시키고 비정상 payload 차단
- `requestId` 기반 추적 로그를 남겨 장애 분석을 용이하게 유지
