# apps/

사용자에게 직접 제공되는 실행 애플리케이션을 관리합니다.

## 하위 구조 제안
- `web/`: 화상채팅 + 게임 패널 UI가 포함된 프론트엔드
- `server/`: 인증, 방(Room), 단어팩 API 등을 제공하는 메인 API 서버

## 기능 분담
### 1) web 앱
- 화상채팅 레이아웃 렌더링
- 게임 버튼 클릭 시 우측 패널(div) 토글
- 게임 상태(라운드, 점수, 힌트, 남은 시간) 시각화
- 사용자 입력(단어 추측), 팀 채팅, 정답/오답 피드백 처리

### 2) server 앱
- 사용자/세션/방 관리 API
- 단어팩 조회 API(언어, 난이도, 주제 필터)
- 게임 생성/참가/종료와 관련된 권한 및 메타데이터 관리
- 결과 저장(학습 이력, 정답률, 빈출 오답)

## 개발 가이드
- UI 이벤트와 도메인 이벤트를 명확히 분리합니다.
- 방 단위 멀티테넌시를 기본 전제로 API를 설계합니다.
- 게임 패널은 화상채팅을 방해하지 않도록 비동기 로딩 및 점진적 렌더링을 고려합니다.
