# services/

앱에서 공통으로 사용하는 독립 서비스(실시간 이벤트, 게임 로직)를 배치합니다.

## 하위 구조 제안
- `realtime/`: WebSocket/WebRTC 시그널링 및 게임 이벤트 브로드캐스트
- `game-engine/`: 단어 맞추기 규칙, 라운드 진행, 점수 계산 엔진

## 기능 분담
### realtime 서비스
- 방 단위 이벤트 라우팅(입장/퇴장/준비/시작/종료)
- 게임 진행 이벤트 동기화(타이머 tick, 정답 판정, 힌트 공개)
- 지연/재접속 대응(상태 스냅샷 재전송)

### game-engine 서비스
- 협동 단어 맞추기 룰 정의
- 언어 학습 친화형 힌트 생성 규칙(품사, 예문, 유사어, 초성/철자 길이)
- 난이도별 점수 정책 및 보너스 규칙
- 라운드 종료/실패 조건 처리

## 개발 가이드
- 게임 규칙 변경은 엔진 서비스에서만 수행하고, UI는 상태를 소비만 하도록 유지합니다.
- 실시간 서비스는 멱등 이벤트 처리와 이벤트 버전 관리 체계를 도입합니다.
- 추후 AI 힌트 생성 모듈 연동을 고려해 인터페이스를 분리합니다.
