# packages/

모노레포에서 재사용되는 공통 패키지를 관리합니다.

## 하위 구조 제안
- `ui/`: 버튼, 패널, 타이머, 점수판 등 공통 UI 컴포넌트
- `shared/`: 공통 타입, DTO, 유틸리티, 상수
- `game-content/`: 단어팩 스키마, 검증기, 콘텐츠 처리 유틸

## 기능 분담
### ui 패키지
- 화상 화면 + 우측 게임 패널 레이아웃 컴포넌트
- 접근성(a11y) 고려 컴포넌트(키보드 조작, ARIA)

### shared 패키지
- 방/유저/게임 상태 타입 공유
- 프론트엔드/백엔드 간 계약(Contract) 단일화

### game-content 패키지
- 언어별 단어 데이터 구조
- 난이도 메타데이터 및 검증 로직
- 잘못된 콘텐츠(중복, 금칙어, 난이도 불일치) 사전 탐지 도구

## 개발 가이드
- 공유 타입 변경 시 앱/서비스 동시 영향 범위를 체크합니다.
- 콘텐츠 스키마는 하위 호환성을 우선합니다.
